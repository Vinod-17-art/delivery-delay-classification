# Delivery Delay Classification

A machine learning project using Python and Scikit-learn to classify a delivery as On Time or Delayed.

## Algorithm
- Random Forest Classifier
- OneHotEncoder for categorical features
- Train/test split
- Classification report
- Confusion matrix

## Features
- Distance in kilometers
- Weather
- Traffic level
- Vehicle type
- Order type
- Preparation time
- Driver experience
- Peak hour

## Target
- On Time
- Delayed

## Installation

```bash
pip install -r requirements.txt
```

## Train the model

```bash
python train_model.py
```

## Make a prediction

```bash
python predict.py
```

The included dataset is synthetic and intended for academic and educational use only.
